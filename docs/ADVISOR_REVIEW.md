# 导师视角内部审阅

这是模拟导师/审稿人的内部自审，不代表真实导师评阅、投稿评审或录取意见。

**当前判断：可以作为有研究训练价值的项目报告；不支持以本轮算法增量直接投稿。**

## 第一问：你到底提出了什么新的问题或方法？

上一阶段暴露了经验积分误差指标对 5 个旧案例低估的问题。本轮把“共振定位是否值得付出成本”写成可检验的问题，方向比继续添加器件演示明确。

但本征能量引导已有文献先例。普通谱基线与极点法都消除了原 5 次低估，新增极点步骤的必要性没有建立。不能用一张更漂亮的窄峰图代替增量贡献。

**已据此修改：**在 README 和报告中撤去创新暗示；保留普通谱强基线；分别报告新案例、后续压力案例和旧数据，避免把已知问题的回归包装成盲验证。

## 第二问：有证据说明原基线不够好吗？

在新增的 36 个物理案例中，原自适应基线也全部满足 0.1% 电流目标。新方法误差更小，但很多案例已远低于目标。人工解析尖峰可以证明有限采样指标会失效，不能证明这些器件一定需要新算法。

**已据此修改：**把物理案例的“基线也达标”作为主要结果；不只展示新方法最准确的一例。未来若研究失败边界，需要独立定义有物理意义的挑战分布，不能反复挑基线失败的点后宣称普遍优势。

## 第三问：参考解是否也会错？

本轮确实发现参考算法舍入警告与细分上限。这类问题在极窄共振下必须正视。50/80 位局部计算与不同求积阶数的交叉检查增强了证据，但定位信息仍有共享，未形成漏峰的数学保证。

**已据此修改：**保留首次未完成运行；对 4 个问题案例单列高精度审计；区分原始未接纳参考与事后复核参考；报告全部精度限制，不把高精度位数当成结果准确位数。

## 第四问：成本是否合算？

旧数据相同目标预算下，谱法需要原方法 1.91 倍、极点法 2.03 倍的实轴能量点。定位本身也有开销。压力研究存在更短的描述性耗时，但极点法相对更简单谱法的优势很小，主研究甚至较慢。不能只按“最坏失效已消失”宣布成功。

**已据此修改：**同时记录本征准备、复数残差、实轴点数和完整耗时；标明计时仅 3 次短重复；不宣称稳定加速。

## 下一道研究门槛

可继续检验一个更窄的假设：**能否仅对高风险积分区间启动谱/极点定位，使可靠性改善的成本低于全局谱初始化？** 这是待验证方向，不是已确认创新点。需要先系统对比已有尖峰自适应与谱网格方法，再冻结新验证集。

可操作的继续标准：

1. 完整取得并复现适当的公开文献基线，明确本方法差别与新增代价。
2. 选择性定位规则只能看在线可获得信息；不能由已知真实误差决定触发。
3. 不隐藏无峰、宽峰、多个相邻峰、接触阈值、根求解失败等情况；加入模型有效域外的明确拒绝状态。
4. 若主张认证，需要真正的误差界或可核验的共振完整性条件。经验覆盖只能称经验覆盖。
5. 在预先固定的新问题上，比较同精度的完整耗时与失败率；若新增步骤未优于普通谱基线，就停止强化该方法主张，转为可靠性基准报告。

这些标准用于限定后续实验，并非本轮已经达成。此时应优先做针对性比较，继续堆更复杂的求解器不能自动补足贡献。

## 面谈中可以诚实讲的内容

“我做了一个共振输运积分的可靠性研究。先发现统计目标能达标但局部误差指标可能低估；再增加谱和极点信息重跑，消除了已知问题，却发现计算量接近翻倍，而且更简单的谱法已经足够。我保留负结果和参考解失败记录，接下来要检验选择性定位是否有增量价值。”

这段表述比宣称“完成高精度 TCAD、准备发表”更经得住追问。面谈价值取决于你是否亲自复现并能解释每一步，项目名称或图的复杂程度本身不保证加分。
