# 复现顺序与理解检查

建议在解压副本中操作，先看现有结果，再逐项运行 README 中的命令。本轮只用个人电脑和纯仿真。

## 第一步：建立物理与数值的区别

阅读 README、METHODS 的模型段，自己画出双势垒与两个接触的带底和化学势。确认：偏压改变预设电势，而非经过电荷自洽求得。

理解检查：为什么把能量积分做得更准，并不意味着材料模型更准？为什么两个相邻窄峰不能都用一个固定宽度代替？

## 第二步：运行测试

运行 `python -W error tests/test_phase3.py`，应看到 11 项通过。其中有独立带状求解器检查、复数极点线宽检查、自由链透射为 1，以及一个解析尖峰反例。

理解检查：尖峰反例为什么能说明误差指标可能失效，却不能说明原基线在真实 RTD 中经常失效？

## 第三步：复现主研究

运行 `python run_study.py`。查看 `results/cases.json` 的 24 个固定案例，以及 `benchmark.csv` 的 72 行方法结果、`references.csv` 的 24 行参考审计、`timings.csv` 的 216 行重复计时。

手工选取一行，以 `|J−Jref|/|Jref|` 复算电流相对误差。不要把无量纲比例 1e−3 和 1e−3% 混淆。检查新方法是否只是超额提高了精度。

## 第四步：理解窄峰与参考失败

运行压力研究，再运行 `python audit_precision.py`。`results_stress/references.csv` 会保留 4 个原始未接纳状态，`precision_audit.csv` 单列其高精度复核结果；`analyze.py` 才将接纳后的参考值用于最终比较。

理解检查：为什么警告不能直接忽略？为什么 50 位和 80 位一致不代表整个算法有 50 位精度？找出窗口外双精度、共享极点定位、Gauss 权重精度三个限制。

## 第五步：按原预算重放旧任务

运行 `python check_legacy.py`，查看三种方法对 11 个任务的结果。手算 `1,447,656 / 713,376 ≈ 2.03`。

理解检查：5 次低估变成 0 次是否证明误差上界成立？为什么这一步只能叫旧数据回归？为什么普通谱基线必须保留？

## 第六步：重画并修改一项假设

运行 `python analyze.py`，自动生成四张图。先保留原始目录，再在副本中只改一个势垒厚度或温度，重新运行并记录差别。该新结果属于你的探索，不能倒填到本轮冻结验证集。

最终应能够不看讲稿解释：模型假设、实部边界本征问题、极点宽度、误差停止条件、独立参考的局限，以及为什么本轮还不适合宣称论文创新。能自己发现问题并做出有记录的修订，才是这个项目的核心训练。
