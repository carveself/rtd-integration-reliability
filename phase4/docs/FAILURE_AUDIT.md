# 选择性方法的回归失败记录

已知 308 个旧样本/候选，在原 CV 与决策预算下重放。选择性方法仍低估 3 项：

| 旧上下文 | item（从 0 起） | 实际误差 / 经验指标 |
|---|---:|---:|
| H-two-well | 1 | 16.7354 |
| D-design | 7 | 2.98835 |
| H-design-two-well | 15 | 2.40835 |

三项均来自上一阶段已发现的问题，故本轮没有解决全部已知低估。最终统计目标仍能达标，恰好说明“目标达标”和“局部误差指标可信”是不同问题。

尚未做宽度阈值、代理面积阈值及模态耦合的独立消融，不能只凭这些数值断言具体哪一条机制造成失败。不得根据这 3 项直接调参后继续声称同批案例为盲验证。

实轴点评估量中，旧 uniform 为 713,376，选择性方法为 764,248，增加的 50,872 正好是所计入的粗探测能量点总量；这表明旧回归中的求积收益不足以抵偿预计算。更严格地说，总数抵消并不证明每个样本面板布局均一致。完整逐项电流、误差、指标位于 `../results_regression/sample_errors.csv`。

该失败应作为公开研究记录保留，不能只发布新案例中的约 12% 节省。
